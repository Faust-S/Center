# Original geospatial programs qualification (public inputs)
A deliberately limited P5.1 benchmark. The original OSRM and Valhalla native images are pinned by linux/amd64 content digests; exact source map is the historical Monaco test extract from OSRM and its Git blob is verified. Attribution: © OpenStreetMap contributors (ODbL 1.0), https://www.openstreetmap.org/copyright. The controlled topology is authored for checking one-way, disconnected and dimension-restricted arcs; not actual roads. No customer data, protected code or credentials. Actual QGIS from Ubuntu 24.04 (exact installed packages and QGIS version recorded) uses native Processing and GeoPackage, not a GIS clone.
Both road engines are built from the same map bytes and run with no network interfaces except loopback. HTTP queries use nsenter to the isolated namespace. Record exact engine images, native versions, input hashes, OSRM Lua hashes, Valhalla config hash, derived graph files, directed matrix, individual route and native geometry, endpoint snap, null/unsupported states, repeated client round-trip measurements, graph preparation wall time, resource snapshot and mismatches. The initial native benchmark compares static car/auto, and observes Valhalla truck profiles on a controlled shortcut vs detour. No implicit fallback speed, no assertion that a matrix cell equals the independently routed path, no assertion of physical clearance. Compare results before selecting an engine. Current comparison is NOT an accepted engine decision, not current live Monaco road data, not an installed IWXA connection or a full truck legality test. Build time and client-inclusive latency are runner observations, not a production performance ranking. Later add turn-restriction, load/traffic and map-update benchmarks, QGIS Windows native integration, exact original U01 Task and Result, verified transfer into OR-Tools and original D11 re-evaluation.
